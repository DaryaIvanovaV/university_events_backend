# Базові заміри (baselines)

Цифри поточної системи **без жодного навчання** — промт + рукописні правила.
Це те, що навчені моделі зобов'язані побити, інакше навчання не має сенсу.

Копії з `reports/` (той каталог у `.gitignore` і на інші машини не їде).

| файл | що міряли |
|---|---|
| `bench_prompt_final.json` | поточний промт на `gemma3:4b`, усі 35 повідомлень: **8/10 пасток, 22/22 анонсів**, медіана 17.0 с |
| `bench_llm.json` | `gemma3:4b` проти `gemma3:1b` — швидкість, частка у VRAM, якість |
| `bench_num_ctx.json` | абляція `num_ctx` (0 / 16384 / 3072) — гіпотеза не підтвердилася |
| `traps_baseline.json` | стан пасток до правки промта |
| `model_comparison_20260906.md` | `gemma3:4b-it-q4_K_M` проти `phi4-mini:3.8b` і `qwen3:4b-instruct-2507` на всіх 35 повідомленнях: заміни `gemma3:4b` не знайдено |

## ⚠ `bench_llm.json` застарілий для 1b

Заміряно `2026-09-01T23:35`, а промт покращено пізніше
(`bench_prompt_final.json`, `2026-09-02T12:37`) — і та правка підняла 4b з
**5/10 до 8/10** на пастках.

**`gemma3:1b` на покращеному промті не ганяли жодного разу.** Її записані 0/10
відображають СТАРИЙ промт. Перед будь-якими висновками про малу модель:

```powershell
ollama pull gemma3:1b          # локально видалено 2026-09-06, треба скачати наново
python -m scripts.bench_llm --models gemma3:1b
```

## `model_comparison_20260906.md` — що там усередині

Зведення трьох прогонів `scripts/check_prompt.py` (по 35 повідомлень кожен),
зібране `python -m scripts.compare_models reports/model_*.json`. Сирі дані і
HTML-звіти для перегляду очима лишилися в `reports/model_*.{html,json}` —
локально, у git їх немає через розмір (~350 КБ на прогін).

Ключова колонка — **«пастки → БД»**: скільки вигаданих подій пережило б і
модель, і детерміновані фільтри, тобто скільки фейкових карток побачив би
модератор. `gemma3` — 0, `phi4-mini` — 5.

## Що з чим порівнювати

Порівняння має бути на однакових даних і однаковим кодом оцінювання
(`scripts/bench_llm.py`, `scripts/check_prompt.py`, `app/eval/grounding.py`).
Якщо скопіювати цей код кудись і дати йому розійтися — порівняння втрачає силу,
а разом із ним і головне твердження роботи.

Окремо про метрику: `announcements_ok` у `bench_llm.py` перевіряє **кількість**
видобутих подій, а не правильність полів. Польову якість міряє
`scripts/check_prompt.py`.
