# Исходники синтетического набора (provenance)

Метод «сначала эталон, потом текст». 200 сообщений, две сотни с разными seed и пулами тем.

1. `gen_slots.py` (seed 20260921, сообщения 3001–3100) и `gen_slots_2.py` (seed 20260922, 3101–3200)
   случайно выбирают параметры каждого сообщения: дату публикации, способ записи даты (явная, диапазон,
   «завтра», «у четвер», «наступної середи», «цього четверга», «через два тижні»…), время, место,
   организатора, аудиторию, ссылку, код онлайн-встречи, подтип ловушки и отвлекающие значения.
   Эталонная дата считается по правилам 1–7 системного промпта. Результат — `slots.json`, `slots_2.json`.
   Вторая сотня смещена туда, где первой было мало: больше сообщений с несколькими событиями,
   переносов (на новую дату, «на завтра», только времени), массовых и индивидуальных консультаций.
2. `texts_1.py` … `texts_8.py` — тексты сообщений, написанные LLM Claude Opus 5 (Anthropic) под эти
   слоты; `OV`/`OVM` — ручные правки неправдоподобных сочетаний (семинар в спортзале, занятие на
   каникулах, защита в воскресенье, поздравление не в день праздника), каждая с комментарием.
3. `build_dataset.py` — собирает `synthetic_messages.json` и детерминированно проверяет эталон
   против текста; файл записывается только при нуле ошибок.
4. `make_audit.py` — выборки для ручной проверки: `audit_sample.md` (25 из первой сотни)
   и `--part2` → `audit_sample_2.md` (15 из второй).

Пересборка (результат побайтово совпадает с опубликованным файлом):
    python gen_slots.py --quiet
    python gen_slots_2.py --quiet
    python build_dataset.py --write
    python make_audit.py
    python make_audit.py --part2
